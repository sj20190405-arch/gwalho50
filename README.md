# 통합과학2 매일 괄호넣기 50

- 학생 화면: GitHub Pages 주소(`https://아이디.github.io/저장소이름/`)
- 결과 저장: 선생님 구글 시트(Apps Script) — 학생에게는 보이지 않음
- 교사 화면: 같은 주소의 **교사** 탭 (비밀번호 0405)

## 1단계. 결과 저장용 Apps Script 만들기 (약 5분)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. (예: `괄호넣기 결과`)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. `Code.gs`의 기존 내용을 모두 지우고 `apps-script/Code.gs` 내용을 전부 붙여넣고 저장합니다.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 승인(‘확인되지 않은 앱’ 경고가 나오면 **고급 → 이동** 클릭)
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 2단계. index.html 에 주소 넣기

`index.html`을 메모장으로 열어 아래 줄을 찾아 따옴표 안에 1단계의 URL을 붙여넣고 저장합니다.

```js
const API_URL = "여기에_웹앱_URL_붙여넣기";
```

## 3단계. GitHub Pages 에 올리기

1. GitHub에서 **New repository** → 이름 입력(예: `gwalho50`) → **Public** → Create
2. **Add file → Upload files**로 `index.html`을 올리고 **Commit changes**
3. **Settings → Pages** → Branch를 `main` / `/(root)`로 선택 → **Save**
4. 1~2분 뒤 `https://아이디.github.io/gwalho50/` 주소가 생깁니다. 이 주소를 학생들에게 공유합니다.

## 운영 메모

- 문제는 한국 시간 자정 기준으로 매일 바뀝니다. 학생마다도 서로 다른 50문항이 나옵니다.
- 교사 탭에서: 날짜·범위·반별 성적, 오답 보기·정답 인정, 학생별 리셋, 날짜별/전체 초기화, 시험 범위 고정, 정답 공개, 재응시 허용 설정
- 결과는 구글 시트 ‘결과’ 탭에도 그대로 쌓이므로 엑셀로 내려받을 수 있습니다.
- 비밀번호 변경: Apps Script **프로젝트 설정 → 스크립트 속성**에 `TEACHER_PW` 추가
